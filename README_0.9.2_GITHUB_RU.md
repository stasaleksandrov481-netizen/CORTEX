# CORTEX 0.9.2 — полный проект

Архив содержит все исходники Android (Kotlin, HTML/CSS/JS) и GitHub Actions.

1. Распакуйте архив.
2. Загрузите **содержимое** папки в корень вашего репозитория GitHub, заменив старые файлы.
3. В GitHub откройте Actions → CORTEX Android APK and Release → Run workflow (либо просто загрузите обновление в main).
4. Дождитесь успешной сборки и скачайте APK в разделе Releases → v0.9.2.

CORTEX CONTROL: https://cortex-control-phi.vercel.app

Добавлено: серверные правила версий, экран технических работ, статистика запусков, ответы поддержки и плавное появление сообщений.

Важно: APK ещё нужно проверить на Android. Публикуется тестовый debug APK; для магазина нужна отдельная подписанная release-сборка.
