# CORTEX 0.8.8 — Island

Отладочная версия Android-приложения с нативным островком поверх других приложений и полировкой интерфейса.

- Островок находится в `CortexIslandService.kt` и интегрирован через `CortexIslandBridge.kt`.
- Переработаны стили, переходы, экраны и анимации.
- Исправлен вызов несуществующего метода при обновлении состояния островка.
- Минимальная Android-версия — Android 8.0 (API 26).

## Установка

В **Assets** скачайте `CORTEX-0.8.8-Island-debug.apk`. Разрешите установку APK из выбранного приложения. В настройках CORTEX отдельно выдайте разрешение «Поверх других приложений» и, при необходимости, уведомления.

**Важно:** это отладочная сборка с debug-подписью GitHub Actions, а не подписанный коммерческий релиз. Подпись может не совпадать с ранее установленной версией. Если Android пишет «Приложение не установлено», может потребоваться удалить старый CORTEX (с потерей локальных данных). Предпочтительно заранее экспортировать доступные данные. Возможности островка и фонового распознавания зависят от версии Android и политики устройства. Воспроизведение на реальном телефоне не подтверждено.

Версия 0.8.8 основана на восстановленном Android-проекте, поэтому не гарантируется стопроцентное совпадение с поведением исходного APK 0.8.6.
