# CORTEX 0.8.8 — полировка интерфейса и исправление островка

- Сохранён нативный островок и его режимы (всегда / по вызову / выключен).
- Исправлена ошибка компиляции в `CortexIslandService`: `Editor.render()` заменён на `Editor.apply()`.
- Снижена нагрузка анимации островка: переразметка выполняется только при изменении размеров.
- Отполированы визуальный контраст, верхние заголовки, стеклянный нижний док и отклик кнопок.
- Выравнены поле ввода, чтение ответов, кнопки истории, настройки и сообщения об ошибках.
- Доработана адаптация на узких экранах и в горизонтальной ориентации.
- Учтены системные настройки уменьшения движения; отрисовка оставлена экономичной.
- Убрано дублирование `enterkeyhint` у поля ввода. Версия приложения и экран «О приложении» синхронизированы.

## Сборка

Открыть проект в Android Studio с установленными Android SDK 36, Gradle 8.13 и JDK 17+; собрать `app > assembleDebug`.
Отладочный APK будет в `app/build/outputs/apk/debug/app-debug.apk`. Он подписывается Android Studio автоматически.
Не устанавливайте APK 0.8.6 из каталога `reference`: он дан только как исторический референс и не содержит нового островка.

**В текущей среде Android SDK и Gradle не установлены; Android APK не был собран и не проверен на устройстве.**
