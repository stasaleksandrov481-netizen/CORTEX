# CORTEX для Android

CORTEX 1.0.6 использует общую очередь визуальных задач в чате и системном островке. Для локальных шагов приложение читает дерево Android и проверяет результат. Если дерево не содержит нужного текста, на Android 11 и новее CORTEX может распознать русский или английский текст на снимке экрана. Для сложных целей и непредвиденных экранов CORTEX запрашивает план через OpenRouter.

## Установка и сборка

- Android 8.0 или новее с актуальным Android System WebView. Голосовой вызов требует поддержки офлайн-распознавания речи на устройстве.
- Для сборки нужны JDK 17 или совместимая версия, Gradle 8.13 и Android SDK Platform / Build Tools 36.
- Команда `./gradlew :app:assembleDebug` создаёт APK в `app/build/outputs/apk/debug/`.
- Для уже установленной Preview 1.0.5 используйте `-PcortexPreview=true`. Он сохраняет её идентификатор `app.cortex.assistant.preview.v105`. Версия 1.0.6 имеет код 106 в обеих сборках.
- Основная версия сохраняет имя **CORTEX** и идентификатор `app.cortex.assistant`. Для установки поверх старой версии Android сверяет сертификат APK.

### Подпись обновления

Подписывайте сборку тем же хранилищем ключей, которым собрали установленный APK. В Android Studio откройте **Build → Generate Signed Bundle / APK → APK**, выберите прежний keystore и вариант `release`. Из командной строки задайте `CORTEX_KEYSTORE_FILE` (абсолютный путь), `CORTEX_STORE_PASSWORD`, `CORTEX_KEY_ALIAS` и `CORTEX_KEY_PASSWORD`, затем запустите `./gradlew :app:assembleRelease`. Для Preview добавьте `-PcortexPreview=true` и используйте ключ её предыдущей сборки.

Сравните сертификаты старого и нового APK командой `apksigner verify --print-certs <путь-к-APK>`. Для опубликованного GitHub-релиза 1.0.5 отпечаток SHA-256 — `ec0318f23ef85abe2b737401fd36e2e578bd96a7b89d4590ea419164a8c271c5`.

Для автоматического выпуска в GitHub сохраните прежнее хранилище ключей в **Settings → Secrets and variables → Actions** как `CORTEX_KEYSTORE_B64` (содержимое файла в Base64). Добавьте `CORTEX_STORE_PASSWORD`, `CORTEX_KEY_ALIAS` и `CORTEX_KEY_PASSWORD`. Публикация выпуска запускается только после проверки сертификата. Без секретов GitHub собирает приложение и запускает тесты. Хранилище ключей и пароли держите отдельно от исходников. Если оригинальный ключ утрачен, опубликованную APK с таким сертификатом Android обновить не сможет.

## Управление экраном

Включите «CORTEX — управление экраном» в специальных возможностях Android через «Профиль → Разрешения Android». Откройте чат или островок и скажите, что нужно сделать. Пример локальной цепочки — «Открой Настройки → Дисплей, прокрути вниз». CORTEX открывает приложение напрямую и проверяет появление окна. Режим «Показывать запуск на экране» в разделе «Вызов» оставляет видимый поиск ярлыка через рабочий стол. Внутри приложений CORTEX использует доступные элементы Android. Сложный запрос можно начать со слова «Действие:», чтобы явно выбрать управление телефоном.

Примеры локальных запросов:

- «Бро, помоги, у меня вайфай выключается и включается модем». CORTEX проверяет Wi-Fi и активный транспорт, ищет переключатель точки доступа и восстанавливает Wi-Fi, если это допускают настройки Android. «Почему выключается Wi-Fi?» запускает диагностику. CORTEX указывает, что подтвердил Android и какие изменения действительно произошли.
- «Открой Telegram, зайди в переписку «Анна» и напиши сообщение: „Привет!“». CORTEX ищет точное название чата, сверяет заголовок переписки и текст в поле, затем запрашивает подтверждение отправки. При неизвестном получателе или тексте CORTEX сначала уточняет. Команда с «без отправки» оставляет текст в поле ввода. Поиск работает с приложениями, которые предоставляют доступные элементы поиска, результатов и переписки.
- «Сколько заряда?», «Включи фонарик», «Домой», «Свайпни вниз» и «Нажми Настройки» выполняются локально при доступности соответствующего действия.

Во время визуальной задачи текущий шаг и кнопка остановки видны в островке у камеры, если островок включён. Команда «Кортекс, убери островок» скрывает его до следующего голосового вызова. «Кортекс, выключись» останавливает задачу, островок, фоновое прослушивание и проверку ответов поддержки. Включить фоновую работу снова можно на вкладке «Вызов».

При сбое можно продолжить с текущего экрана командой «Продолжи». План на паузе хранится до завершения процесса CORTEX. В «Разрешениях Android» можно открыть журнал задач.

Снимки для распознавания обрабатываются на устройстве. Локальные команды и их ответы исключаются из контекста разговорной модели. Для сложной визуальной задачи за один запуск допускается до двух запросов модели. Передача текста открытого экрана серверу и OpenRouter требует согласия, которое можно отозвать в «Профиль → О приложении → Конфиденциальность». Для отправки, удаления и других необратимых действий CORTEX запрашивает подтверждение. Пароли, системные запросы доступа и защищённые окна требуют действий пользователя. Для оцениваемой работы на Учи.ру пользователь сам сдаёт результат. Возможность выполнить шаг зависит от интерфейса конкретного приложения.

Модели распознавания русского и английского взяты из [tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/65727574dfcd264acbb0c3e07860e4e9e9b22185) под Apache-2.0. Лицензия включена в `app/src/main/assets/ocr/`.

## Голосовое управление

Разрешите микрофон и включите «Кортекс» в настройках управления телефоном для активации в фоне. Микрофон в чате поддерживает диктовку, а кнопка с волной отправляет распознанную команду. Ответы и статусы отображаются текстом.

## Вход через Google

Приложение открывает OAuth в браузере Android. Сервер CORTEX проверяет ответ через PKCE, возвращает пользователя по `app.cortex.assistant://oauth/return` (в Preview используется собственная схема) и выдаёт сессию по отдельному HTTPS-запросу. Сессия шифруется ключом из Android Keystore.

Для Google-входа нужен OAuth-клиент типа Web application в Google Auth Platform. В Authorized redirect URIs добавьте `https://jjcqrjztxohnifmziksy.supabase.co/auth/v1/callback`. Включите Google в Supabase Auth → Sign In / Providers и заполните поля Client ID и Client Secret. В Supabase Auth → URL Configuration оставьте разрешёнными `https://jjcqrjztxohnifmziksy.supabase.co/functions/v1/cortex/v1/auth/callback/*` и `https://cortex-control-phi.vercel.app/`. Если OAuth-клиент в режиме Testing, добавьте аккаунты, которые будут проверять вход.

## Сервер и панель

Код действующего шлюза находится в supabase/functions/cortex, исходники панели CORTEX Control — в cortex-control. Шлюз принимает только модели OpenRouter с суффиксом :free и ограничивает стоимость входных и выходных токенов нулём. Ключ хранится в Supabase через OPENROUTER_API_KEY или существующий серверный Vault.

Вход в панель проверяет роль и MFA Supabase. Приглашения владельца и разработчика проверяются существующими серверными функциями. Адрес панели и разрешённые перенаправления Auth должны совпадать с https://cortex-control-phi.vercel.app/.

Шлюз привязывает новое обращение к аккаунту или текущей установке. У прежних обращений без сохранённой привязки владелец может быть неизвестен. Такие обращения остаются в панели поддержки. Оповещения о новых ответах включаются в «Настройки → Уведомления».

Проверьте шлюз командой `node --experimental-transform-types --test supabase/functions/cortex/handler.test.ts`.
Проверьте разбор плана и обработку голосового вызова командой `./gradlew :app:testDebugUnitTest`.
Для сборки панели откройте папку cortex-control и выполните npm ci и npm run build.

Миграция Supabase после удаления озвучки переносит прежний каталог в закрытую схему и убирает его из публичного API.
