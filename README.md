# CORTEX для Android

CORTEX 1.0.5 использует общую очередь визуальных задач в чате и системном островке. Для локальных шагов приложение читает дерево Android и проверяет результат. Если дерево не содержит нужного текста, на Android 11 и новее CORTEX может распознать русский или английский текст на снимке экрана. Для сложных целей и непредвиденных экранов CORTEX запрашивает план через OpenRouter.

## Установка и сборка

- Android 8.0 или новее с актуальным Android System WebView. Голосовой вызов требует поддержки офлайн-распознавания речи на устройстве.
- Для сборки нужны JDK 17 или совместимая версия, Gradle 8.13 и Android SDK Platform / Build Tools 36.
- Команда `./gradlew :app:assembleDebug` создаёт APK в `app/build/outputs/apk/debug/`.
- Флаг `-PcortexPreview=true` даёт сборке 1.0.5 идентификатор `app.cortex.assistant.preview.v105`. Preview устанавливается рядом с основной версией и требует собственных разрешений.
- Обновление основной версии требует идентификатор `app.cortex.assistant` и совпадающую подпись.

## Управление экраном

Включите «CORTEX — управление экраном» в специальных возможностях Android через «Профиль → Разрешения Android». Откройте чат или островок и скажите, что нужно сделать. Пример локальной цепочки — «Открой Настройки → Дисплей, прокрути вниз». CORTEX переходит на рабочий стол, ищет ярлык и нажимает видимые элементы. Сложный запрос можно начать со слова «Действие:», чтобы явно выбрать управление телефоном.

Во время визуальной задачи текущий шаг и кнопка остановки видны в островке у камеры, если островок включён. Команда «Кортекс, убери островок» скрывает его до следующего голосового вызова. «Кортекс, выключись» останавливает задачу, островок, фоновое прослушивание и проверку ответов поддержки. Включить фоновую работу снова можно на вкладке «Вызов».

При сбое можно продолжить с текущего экрана командой «Продолжи». План на паузе хранится до завершения процесса CORTEX. В «Разрешениях Android» можно открыть журнал задач.

Снимки для распознавания обрабатываются на устройстве. Передача текста открытого экрана серверу и OpenRouter требует согласия, которое можно отозвать в «Профиль → О приложении → Конфиденциальность». Для отправки, удаления и других необратимых действий CORTEX запрашивает подтверждение. Пароли, системные запросы доступа и защищённые окна требуют действий пользователя. Для оцениваемой работы на Учи.ру пользователь сам сдаёт результат. Возможность выполнить шаг зависит от интерфейса конкретного приложения.

Модели распознавания русского и английского взяты из [tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/65727574dfcd264acbb0c3e07860e4e9e9b22185) под Apache-2.0. Лицензия включена в `app/src/main/assets/ocr/`.

## Голоса и озвучка

Откройте «Профиль → Настройки → Голос». Переключатель «Озвучка Кортекса» действует в чате и островке. «Читать текстовые ответы вслух» включает голос также для сообщений, набранных вручную. Системный голос берётся из Android. Выбранный скачиваемый голос работает локально после установки.

Первое скачивание голоса Silero занимает около 86,5 МБ. Голоса из одного пака используют общие данные. Скачиваемые движки поддерживаются на ARM64 и x86-64. Лицензии и ссылки на исходники движков есть в `app/src/main/assets/voice/NOTICE.txt`.

### Добавление своего профиля RuVoice

1. В RuVoice TTS выберите нужный профиль, затем откройте «⋮ → Экспорт настроек». Сохраните JSON.
2. Загрузите JSON в Assets публичного GitHub Release. У каждого файла должна быть прямая ссылка вида `https://github.com/OWNER/REPO/releases/download/TAG/FILE.json`.
3. В [CORTEX Control](https://cortex-control-phi.vercel.app/) откройте «Голоса». Укажите название, уникальный идентификатор, формат «Экспорт RuVoice» и ссылку. Панель получит размер и SHA-256 из GitHub. Включите показ в каталоге и сохраните.
4. Пользователь открывает «Голос», нажимает «Скачать» и может сразу прослушать результат. При необходимости он обновляет список кнопкой рядом с заголовком.

Поддерживаются экспорты RuVoice TTS формата v1/v2 с выбранным штатным голосом Silero v5.5 (`aidar`, `baya`, `eugene`, `kseniya`, `xenia`). CORTEX читает активный профиль, темп, высоту, громкость, частоту дискретизации, паузы и простые пользовательские ударения. Специальные правила читалки, словари замен и отдельный голос прямой речи требуют поддержки конкретных правил RuVoice. Данные штатного пака Silero v5.5 распространяются под CC BY-NC-SA 4.0.

### Добавление своего нейросетевого голоса

Для нового персонажа можно обучить голос на разрешённых записях и экспортировать модель в совместимый с sherpa-onnx формат VITS/Piper. В корень ZIP положите `model.onnx`, `tokens.txt`, `espeak-ng-data/` (или подходящий для модели `lexicon.txt`) и `voice.json`. Пример настроек для модели с одним русским голосом:

```json
{"schema": 1, "engine": "vits", "language": "ru-RU", "speaker": 0, "rate": 1}
```

Загрузите ZIP в GitHub Release и добавьте через тот же экран с форматом «Пакет CORTEX». CORTEX проверяет размер, SHA-256 и пробный синтез перед выбором. Возможность установить модель позволяет менять голос персонажа без пересборки приложения. Сходство зависит от обученной модели и записей.

Для публикации без админ-панели добавьте запись в `voices/catalog.json` в ветке `main`. Поля записи `id`, `title`, `description`, `version`, `kind` (`ruvoice-preset` или `zip`), `url`, `size_bytes` и `sha256`. Прямые ссылки на `raw.githubusercontent.com` также поддерживаются в этом каталоге. Для нового файла увеличьте версию. Резервные идентификаторы `android`, `ruvoice-eugene`, `ruvoice-aidar` и `ruvoice-xenia` относятся к встроенным пунктам каталога.

## Вход через Google

Приложение открывает OAuth в браузере Android. Сервер CORTEX проверяет ответ через PKCE, возвращает пользователя по `app.cortex.assistant://oauth/return` (в Preview используется собственная схема) и выдаёт сессию по отдельному HTTPS-запросу. Сессия шифруется ключом из Android Keystore.

Для Google-входа нужен OAuth-клиент типа Web application в Google Auth Platform. В Authorized redirect URIs добавьте `https://jjcqrjztxohnifmziksy.supabase.co/auth/v1/callback`. Включите Google в Supabase Auth → Sign In / Providers и заполните поля Client ID и Client Secret. В Supabase Auth → URL Configuration оставьте разрешёнными `https://jjcqrjztxohnifmziksy.supabase.co/functions/v1/cortex/v1/auth/callback/*` и `https://cortex-control-phi.vercel.app/`. Если OAuth-клиент в режиме Testing, добавьте аккаунты, которые будут проверять вход.

## Сервер и панель

Код действующего шлюза находится в supabase/functions/cortex, исходники панели CORTEX Control — в cortex-control. Шлюз принимает только модели OpenRouter с суффиксом :free и ограничивает стоимость входных и выходных токенов нулём. Ключ хранится в Supabase через OPENROUTER_API_KEY или существующий серверный Vault.

Вход в панель проверяет роль и MFA Supabase. Приглашения владельца и разработчика проверяются существующими серверными функциями. Адрес панели и разрешённые перенаправления Auth должны совпадать с https://cortex-control-phi.vercel.app/.

Шлюз привязывает новое обращение к аккаунту или текущей установке. У прежних обращений без сохранённой привязки владелец может быть неизвестен. Такие обращения остаются в панели поддержки. Оповещения о новых ответах включаются в «Настройки → Уведомления».

Проверьте шлюз командой `node --experimental-transform-types --test supabase/functions/cortex/handler.test.ts`.
Проверьте разбор плана и обработку голосового вызова командой `./gradlew :app:testDebugUnitTest`.
Для сборки панели откройте папку cortex-control и выполните npm ci и npm run build.
