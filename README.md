# CORTEX для Android

CORTEX 1.0.1 работает в чате и в системном островке. Цепочки системных команд выполняются в одной очереди Android. Для действий внутри выбранного приложения CORTEX составляет план, анализирует доступные элементы экрана и проверяет результат каждого шага.

## Установка и сборка

- Android 8.0 или новее. Для работы чата нужен актуальный Android System WebView.
- Сборка из исходников требует JDK 17, Gradle 8.13 и Android SDK Platform / Build Tools 36.
- Соберите APK командой `./gradlew :app:assembleDebug`. Файл появится в app/build/outputs/apk/debug/.
- Флаг `-PcortexPreview=true` даёт сборке 1.0.1 идентификатор `app.cortex.assistant.preview.v101`. Она устанавливается рядом с предыдущими версиями. Разрешения выдаются для этой сборки отдельно.
- Обновление установленного приложения требует исходного идентификатора app.cortex.assistant и совпадающей подписи.

## Управление экраном

Откройте «Профиль → Доступы Android → Управление экраном», включите службу CORTEX и вернитесь в приложение. Укажите название приложения и цель, например «найди в Яндекс Браузере расписание электричек». Из островка можно также сказать «проверь этот экран». Для каждой задачи CORTEX запрашивает разрешение на передачу подписей, заголовков и видимых ошибок выбранного приложения в OpenRouter.

Островок и уведомление показывают состояние задачи. Остановить её можно в чате, мини-окне островка или уведомлении. В «Доступах Android» доступен журнал проверенных шагов.

Команда «сделай фото» открывает предпросмотр с отсчётом и кнопкой отмены. Android запрашивает доступ к камере при первой съёмке. Начиная с Android 10, снимки сохраняются в альбоме CORTEX. На Android 8–9 используется папка Pictures приложения.

Для Wi-Fi и VPN CORTEX открывает системные панели. Google Play получает запрос поиска, установку пользователь подтверждает сам. Оплату, системные разрешения, ввод паролей и работу с защищёнными окнами выполняет пользователь. Доступность остальных действий зависит от дерева элементов конкретного приложения.

## Сервер и панель

Код действующего шлюза находится в supabase/functions/cortex, исходники панели CORTEX Control — в cortex-control. Шлюз принимает только модели OpenRouter с суффиксом :free и ограничивает стоимость входных и выходных токенов нулём. Ключ хранится в Supabase через OPENROUTER_API_KEY или существующий серверный Vault.

Вход в панель проверяет роль и MFA Supabase. Приглашения владельца и разработчика проверяются существующими серверными функциями. Адрес панели и разрешённые перенаправления Auth должны совпадать с https://cortex-control-phi.vercel.app/.

Шлюз привязывает новое обращение к аккаунту или текущей установке. У прежних обращений без сохранённой привязки владелец может быть неизвестен. Такие обращения остаются в панели поддержки. Оповещения о новых ответах включаются в «Настройки → Уведомления».

Проверьте шлюз командой `node --experimental-transform-types --test supabase/functions/cortex/handler.test.ts`.
Проверьте разбор голосовой команды и порядок исполнения командой `./gradlew :app:testDebugUnitTest`.
Для сборки панели откройте папку cortex-control и выполните npm ci и npm run build.
