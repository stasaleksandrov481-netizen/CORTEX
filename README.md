# CORTEX · AI Control Center

Русскоязычный прототип Android-ассистента. Интерфейс написан на HTML, CSS и JavaScript. Kotlin-оболочка открывает его в Android WebView. Волны, знак CORTEX и иконки выполнены в векторе.

## Посмотреть интерфейс

Скачайте репозиторий через **Code → Download ZIP**, распакуйте его и откройте `app/src/main/assets/web/index.html` в Chrome или Edge. На ПК откроется вид с телефоном, на узком экране интерфейс займёт всё окно.

Главная, история, ассистенты, профиль, память, инструкции и настройки работают локально. Команды запуска Telegram, поиска файлов и голосового ввода показывают демонстрационные сценарии. Заметки, пользовательские профили, выбор цвета и другие параметры сохраняются на устройстве.

## Подключить ответы ИИ

1. Откройте **Настройки → Подключение → Добавить ключ**.
2. Введите свой [ключ OpenRouter](https://openrouter.ai/settings/keys) и нажмите **Подключить**.
3. Нажмите **Проверить**, затем задайте текстовый вопрос на главной. После ответа можно отправить уточнение.

CORTEX использует [Free Models Router](https://openrouter.ai/openrouter/free). Он выбирает доступную бесплатную модель. CORTEX отвечает от своего имени спокойным деловым тоном. OpenRouter получает текст вопроса, инструкции активного профиля и до шести последних реплик для уточнения. Записи памяти остаются в локальном интерфейсе.

На Android ключ сохраняется зашифрованным с помощью Android Keystore. В браузере он действует до перезагрузки или закрытия страницы. Удалить ключ можно в том же разделе. Журнал ответов управляется через **Настройки → Приватность**.

## Скачать APK с GitHub

GitHub Actions собирает тестовый APK при каждом пуше в `main`. Откройте **Actions → Android APK**, выберите успешный запуск и скачайте **CORTEX-debug.apk** из раздела **Artifacts**. Для ручной сборки нажмите **Run workflow** на странице процесса.

## Собрать Android-проект

Требуются JDK 17–25, Android SDK Platform 36 и Android SDK Build-Tools 36.0.0. Для первого запуска Gradle нужен интернет. Минимальная версия на устройстве — Android 8.0.

В PowerShell из корня репозитория укажите свой путь к JDK и SDK. Ниже указаны стандартный каталог SDK и Java из Android Studio.

```powershell
$env:JAVA_HOME = 'D:\Program Files\Android Studio\jbr'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat --no-daemon :app:assembleDebug
```

На macOS или Linux установите переменные `JAVA_HOME` и `ANDROID_HOME`, затем выполните `./gradlew --no-daemon :app:assembleDebug`. Результат локальной сборки появится в `app/build/outputs/apk/debug/`.

## Структура

- `app/src/main/assets/web/` — экраны, стили, локальное состояние, браузерное подключение к OpenRouter и векторные иллюстрации.
- `app/src/main/java/app/cortex/assistant/` — Android WebView, защищённое хранение ключа и запросы к OpenRouter.
- `gradle/wrapper/` — Gradle Wrapper с проверкой контрольной суммы дистрибутива.
